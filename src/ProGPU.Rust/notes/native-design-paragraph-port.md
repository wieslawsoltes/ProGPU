Ports the ordinary `paragraph_layout_core` producer, `valid_style_runs`, tab/inline admission, `append_logical_bidi_run`, continuation remapping and original measured-line publication. Reuses the already ported original native fallback, Unicode, shaper and measured writer. The architecture research in DESIGN.md governs immutable CPU ownership only; no foreign executor or source code is used.

`NativeDesignParagraph::shape` accepts complete immutable faces, scalar input, optional explicit `NativeDesignStyle` coverage, actual native shaping request, `NativeDesignOptions` and optional `NativeInlineFlow`. Empty style inventory selects original grapheme-preserving preferred-first fallback. Styled runs retain independent features, language, scale and contextual/source-bidi number policy. All substitution, bidi, scripts, graphemes, fallback, line breaks and actual `NativeRun` generations remain owned by `NativeDesignSource`.

The original complete-paragraph run partition and full context precede continuation selection. Logical output restores RTL cluster-group order without reversing glyphs inside a cluster. Generic ABI Y negation preserves INT_MIN exactly; this is independent from the device route's checked-negation admission. Inline objects retain original sentinel/font/width/metrics slots, tabs retain their original paragraph level and font selection, and each real glyph retains its actual run/glyph owner. Ellipsis remains the original caller-selected primary-face synthetic glyph with no fabricated run owner.

Actual native fitting supports raw float widths, incremental tabs, emergency/whole-word breaking, alignment/justification, original trimming/collapse, intrinsic widths, fixed or caller-resolved line metrics and continuation at an existing full-paragraph cluster. `reflow` shares all immutable font/run/source owners and reruns only placement; switching tab reinterpretation on/off requires a new shaping generation because it changes run partitioning. Positive tab grids, ordinary measures, alignment and supported continuation may change. Source-double/ideal-unit policy remains in `NativeSourceParagraph`.

Candidate arrays are private until the complete paragraph is published. `copy_into` checks every destination capacity before writing used prefixes and preserves unused tails. Safe owned buffers replace native caller scratch/ABI pointer aliasing; these APIs do not claim allocation-free execution or native plan-cache counters. Rust font sources are retained `SfntFace` owners, not newly invented native context identities.

This checkpoint completes ordinary horizontal orchestration, not exclusion/floating fragment flow or vertical writing/interaction. Those independent original writers remain subsequent implementation work. Generic unhinted paragraph-to-render-geometry transport also remains separate from captured hinted geometry. No external hinted provider, source pixels or package/browser qualification is implied. Per the user's implementation-first instruction, no compilation, tests, fixtures, browser runs or benchmarks were performed.
