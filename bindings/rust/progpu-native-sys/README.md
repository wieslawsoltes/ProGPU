# progpu-native-sys

Raw Rust bindings of the ProGPU native C ABI (`progpu_native.h`, ABI version 5) and of the
wgpu-native WebGPU C ABI the engine runs on (`webgpu.h` and `wgpu.h` of wgpu-native
`33133da`, webgpu-headers `aef5e42`), generated by `bindgen` (`regenerate.sh`).

The libraries are loaded at run time (`Runtime::load`) from the ProGPU native SDK packages of this
crate's version. The build script prepares them for the target: it uses `PROGPU_NATIVE_SDK_DIR`
(a directory with `include/`, `runtime/` and `sdk/`), or downloads the pinned NuGet packages
(`ProGPU.Backend.Native`, `ProGPU.Native.Sdk` and the wgpu-native runtime
`Silk.NET.WebGPU.Native.WGPU` 2.23.0) once into a cache (`PROGPU_NATIVE_CACHE`, else the user cache
directory), verifies their SHA-256 and extracts what the target needs. Crates that compile C or
C++ against the SDK read `DEP_PROGPU_NATIVE_INCLUDE`, `DEP_PROGPU_NATIVE_SDK` and
`DEP_PROGPU_NATIVE_RUNTIME`.

`tests/headless.rs` creates a wgpu-native device, the engine on it, renders a frame of rectangles
and reads it back.
